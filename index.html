RodTasks

Dock de Tarefas, Calendário, Rotina e Sticky Notes para Windows 10 Mobile.

Versão publicada aqui agora: carregando…

O RodTasks é sideloaded, não distribuído pela Microsoft Store — assinado com um certificado autoassinado em vez de uma conta de desenvolvedor paga, e compilado com .NET Native (a ferramenta de build moderna não empacota mais o runtime pra ARM de 32-bit sozinha). Por isso são alguns downloads, mas só dois são instalação única.

1 No telefone: Configurações → Atualização e segurança → Para desenvolvedores, ligue o Modo desenvolvedor.

2 Baixe e instale o certificado. Só precisa uma vez por aparelho.

Baixar certificado (.cer)

3 Baixe e instale esses dois pacotes de framework, nessa ordem. Também só precisa uma vez por aparelho.

Baixar .NET Native Framework (.appx)
Baixar .NET Native Runtime (.appx)

4 Baixe e instale o app.

Baixar RodTasks (.appxbundle)

Se o Windows avisar sobre um publicador não confiável, instale o certificado do passo 2 primeiro e tente de novo. Se o app instalar mas fechar na hora, sem nem mostrar a splash screen, o passo 3 não foi feito.

Já tem o RodTasks instalado? O próprio app checa version.json sozinho ao abrir e mostra um botão de atualizar quando tem versão nova — não precisa voltar aqui pra cada atualização.

App pessoal, sem outros usuários. Este repositório só distribui os binários — o código-fonte fica num repositório privado separado.
